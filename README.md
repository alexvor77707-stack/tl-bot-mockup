# TL Bot — Макет админ-панели (GRAMGPT)

Интерактивный макет интерфейса: Менеджер аккаунтов, Пул прокси, Управление аккаунтом, Добавление и Импорт.

## Как открыть

1. Скачайте файл `TL_Bot_MOCKUP_FINAL.html` (кнопка **Code → Download ZIP** или значок скачивания на странице файла)
2. Откройте его в браузере (Chrome / Edge / Firefox) — интернет не нужен, всё в одном файле

## Что проверить

- Кнопка **Пул прокси** — открывает пул, кнопка становится активной
- Клик по **аватару / имени аккаунта** в таблице — окно управления (8 вкладок)
- **+ Добавить** и **Импорт** — мастера добавления
- Escape / крестик / клик по фону — закрытие окон
